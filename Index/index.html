Introdução ao MVC

O padrão MVC(Model-View-Controller é uma aquitetura de software utilizada no desenvolvimento de aplicações para separar a lógica de negócios, a interface do usuário e o controle dos dados.

Componentes do MVC

  • Model (Modelo) - Representa os dados e a lógica de negócio da aplicação.
  • View (Visão) - Responsável pela interface com o usuário e exebição dos dados.
  • Controller (Controlador) - Intermedia a comunicação entre a Model e View.
